Design Lasagna Schemas Language Server Examples

Language Server

Completions, diagnostics, and code actions for components, tokens, and utility classes.

Package discovery

Add fields to your package.json and the language server picks up your design system automatically.

{
  "customElements": "dist/custom-elements.json",
  "designSystem": {
    "tokens": "dist/tokens.json",
    "utilities": "dist/utilities.json"
  }
}

Local config

For monorepos or custom setups, use a local config file.

{
  "sources": {
    "components": ["packages/components/dist/custom-elements.json"],
    "tokens": ["packages/tokens/dist/tokens.json"],
    "utilities": ["packages/css/dist/utilities.json"]
  }
}

Deprecation severity

Diagnostics escalate as the removal date approaches.
