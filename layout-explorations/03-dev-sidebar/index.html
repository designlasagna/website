Make systems make sense.

Open tools for design tokens, schemas, and better editor workflows. Install, point an editor at your tokens, and start reading your system.

# add the schemas to your project
$ npm install @designlasagna/schemas

# or just point your editor at them
$ git clone https://github.com/designlasagna/schemas

The tasty parts

We are deliberately not another format or platform. Design Lasagna works with the Design Tokens Community Group standard — if it has a DTCG file, it should work here.
