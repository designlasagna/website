Version 0.3.0

v0.3.0Current2026-09-06

This release establishes the v0.3 schema family and pairs it with human-readable field guidance.

Migration note

Consumers moving from a previous manifest should validate against the new version explicitly. Do not silently change an existing schema version.

Added

  • Versioned token, utility, and component schemas.
  • Reader-facing examples and usage guidance for every documented field.

Changed

  • Nested references are now presented with short, linkable definition names in documentation.
