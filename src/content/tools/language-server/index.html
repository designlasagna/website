More examples: migration guidance and component details

What the language server can do

Features draw on the information in your manifests and the syntax supported by your editor integration.

Component completions

  • Custom-element tags, attributes, and allowed values
  • Named slot suggestions
  • Lit .property and @event bindings

Tokens and CSS

  • Token suggestions in var(), with resolved values
  • Component-scoped CSS custom properties
  • Exposed CSS part names in ::part()

Utility classes

  • Class suggestions and descriptions from utility manifests
  • Configurable class attribute names
  • Static class names in Lit classMap calls

Hover information

  • Component APIs, attributes, values, and slots
  • Token values and utility descriptions
  • Deprecation details and replacement guidance where provided

Diagnostics

  • Deprecation warnings for components, attributes, individual values, tokens, and classes
  • Severity that escalates as removal dates approach
  • Schema validation for discovered token documents, with JSON and JSONC error locations

Migration quick fixes

  • Replace deprecated tokens and utility classes
  • Update deprecated attributes and individual attribute values
  • Apply targeted edits when the manifest supplies a valid replacement
