v0.2.0VS Code extensionPre-Release2026-10-02

VS Code Pre-Release

Published the VS Code extension v0.2.0 as a pre-release. Verified on VS Code 1.90.2 and 1.138. Includes completion, hover, diagnostics, settings reload, and Quick Fix actions. Minimum VS Code version is 1.90. The extension bundles the server; no separate npm install is needed in VS Code.
