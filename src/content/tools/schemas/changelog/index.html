v0.4.0

Lifecycle contracts

Added the v0.4 contracts under /schemas/v0.4/, with a canonical status field, an explicit deprecated: false, and a shared lifecycle fragment for deprecation records. Token platform mappings are now closed and no longer accept usage. v0.3 documents stay valid against the v0.3 contracts. See the migration guide.
