# Self-hosted fonts

Latin subset woff2 files, downloaded from Google Fonts. All are licensed under the SIL Open Font License 1.1 (see the OFL-*.txt files).

- Tilt Warp 400 (tilt-warp-400.woff2): https://fonts.google.com/specimen/Tilt+Warp, OFL-tiltwarp.txt
- DM Sans 400-500, variable (dm-sans-variable.woff2): https://fonts.google.com/specimen/DM+Sans, OFL-dmsans.txt
- DM Mono 400 and 500 (dm-mono-400.woff2, dm-mono-500.woff2): https://fonts.google.com/specimen/DM+Mono, OFL-dmmono.txt
